## 🎮 โครงสร้างและเนื้อเรื่องในเกมส์

### 1. หน้าเลือกตัวละคร (Character Customization)
- **เพศ:** ชาย / หญิง
- **สีหน้า:** 😄 ยิ้มสู้ / 😴 หน้าง่วง / 😤 หน้างอน
- **ชุดประจำกาย:**
  - ชาย: ⚽ ชุดบอล+แตะ, 🐥 ชุดชูชีพเป็ดเหลือง, 🌾 ชุดผ้าขาวม้า+งอบ
  - หญิง: 🫘 ชุดนอนลายถั่ว, 🦺 ชุดชูชีพชมพู, 👩‍🍳 ชุดแม่ค้า
- **ระดับความยาก:**
  - 🟢 ง่าย: ซอยถั่วเขียว (น้ำขึ้นช้า + เริ่มต้นมีบัตร ปชช. ฟรี)
  - 🟡 ปานกลาง: ซอยถั่วแดง บางปลา 12
  - 🔴 ยาก: ซอย กทม. น้ำท่วมสูงจริง (ลาดพร้าว 101, ราม 24, ดอนเมือง)

### 2. ด่าน 1: เก็บของหนีน้ำ (Flood Escape)
- น้ำท่วมสูงขึ้นเรื่อยๆ จาก 20% ถึง 100%
- ต้องจิ้มเก็บเอกสารสำคัญ 3 อย่างให้ครบใน 40 วินาที:
  - 🪪 บัตรประชาชน
  - ⚡ บิลค่าไฟ
  - 📸 รูปถ่ายน้ำท่วม
- ระวังสิ่งของลอยน้ำกวนประสาท (กะละมังแดง, จระเข้ยาง, แตะช้างดาว)
- **ฉากแพ้:** วงดนตรีชุดกันฝนสีเหลือง 4 คน เล่นเพลงแตรวงงานวัด พร้อมป้ายไฟนีออน *"แพ้แล้วจ้าาา"*

### 3. ด่าน 2: เซเว่นหมด ไปตลาดโฟม (Floating Foam Market)
- เซเว่นของหมด ต้องไปแย่งของที่ตลาดโฟมลอยน้ำที่โคลงเคลง
- แข่งกับ NPC ชาวบ้าน 5 คน แย่งซื้อ มาม่า, น้ำดื่ม, ชาเย็น
- ต้องได้ **มาม่า 1 + น้ำดื่ม 1** เป็นอย่างน้อย
- **กล่องทองอัลติเมต:** ลอยน้ำมา 3 วินาที หากเก็บทัน จะได้รับ 9,000 บาทเต็มทันทีในด่าน 3!
- **มีกัน จอมพลัง:** ขี่ห่วงยางเป็ดมาช่วยกู้ชีพ 1 ครั้งต่อเกมส์!

### 4. ด่าน 3: FINAL BOSS ล่า 9,000 ที่ อบต. (Bureaucracy Battle)
- เจอกับเจ้าหน้าที่ อบต. สุดเขี้ยว ตรวจเอกสาร 3 ช่อง
- ตอบผิดหรือเอกสารไม่ตรง เงินลดลงทีละ 1,000 บาท (เริ่มต้น 9,000 บาท ต่ำสุด 3,000 บาท)
- ผิดครบ 3 ครั้ง = แพ้
- **สกิลเรียกคนส่งเอกสารด่วน (4 ครั้ง):**
  - Grab / LINE MAN / BOLT (หักค่าส่ง 500 บาท มาส่งทันที)
  - วินมอไซค์หมู่บ้าน (ฟรี 0 บาท แต่ต้องรอเสียงเครื่องยนต์ 4 วินาที)

### 5. ฉากจบ 3 แบบ
- 🏆 **9,000 บาทเต็ม:** *"โอนเงินสำเร็จ 9,000 บาท! เลี้ยงชาเย็นทั้งหมู่บ้าน"*
- 💰 **5,000 - 8,500 บาท:** *"ช่วยได้แค่นี้ครับ"*
- 🪙 **3,000 บาท:** *"ได้น้อยแต่ก็ยังดี"*

## 🚀 วิธีนำขึ้นเว็บไซต์บน GitHub (GitHub Pages)

โปรเจกต์นี้ตั้งค่า `base: './'` และใส่ไฟล์ GitHub Actions Workflow ไว้อัตโนมัติแล้ว สามารถนำขึ้น GitHub ได้ง่ายๆ ในไม่กี่ขั้นตอน:

### ขั้นตอนที่ 1: สร้างและ Push ขึ้น GitHub Repo
```bash
# ตรวจสอบสถานะและ Commit
git init
git add .
git commit -m "Initial commit - Thai Flood Comedy Game"

# สร้าง repo บน github.com แล้วสั่ง push
git branch -M main
git remote add origin https://github.com/<YOUR-USERNAME>/<YOUR-REPO-NAME>.git
git push -u origin main
```

### ขั้นตอนที่ 2: เปิดใช้งาน GitHub Pages
1. เข้าไปที่ Repository ของคุณบน **GitHub**
2. ไปที่แท็บ **Settings** -> เมนูด้านซ้ายเลือก **Pages**
3. ตรงหัวข้อ **Build and deployment**:
   - ช่อง **Source** ให้เลือกเป็น: **`GitHub Actions`**
4. ระบบจะรันไฟล์ `.github/workflows/deploy.yml` โดยอัตโนมัติ (ใช้เวลาประมาณ 1-2 นาที)
5. เมื่อเสร็จสิ้น คุณจะได้ URL เว็บไซต์ เช่น:
   ```
   https://<YOUR-USERNAME>.github.io/<YOUR-REPO-NAME>/
   ```
   สามารถคลิกเข้าเล่นและแชร์ให้เพื่อนเล่นได้ทันที! 🎉
